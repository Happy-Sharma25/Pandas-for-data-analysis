A collection of Pandas programs covering the core concepts required for data analysis using Python.

## About

This repository documents my journey of learning **Pandas** as part of my Data Analytics roadmap. It contains beginner-to-intermediate examples that demonstrate how to work with Series and DataFrames, inspect data, and understand the basic structure and properties of a dataset.

## Topics Covered

- Introduction to Pandas
- Data Frames
- Data Selection
- Data Filtering
- Adding new column to the data
- Rename and Drop Columns/Tables
- Handle missing values
- String Operations
- Date Time Functions
- Group By
- Merge, Join and Concat
- Pivot Table
- Reading Files

## Prerequisites

Install pandas using pip:

```bash
pip install pandas
```

## Run the Programs

Clone the repository:

```bash
git clone https://github.com/Happy-Sharma25/pandas-for-data-analysis.git
```

Navigate to the project folder:

```bash
cd pandas-for-data-analysis
```

Run any Python file:

```bash
python 01_introduction_pandas.py
```
